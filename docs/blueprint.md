# **App Name**: Verdant Planner

## Core Features:

- Task Creation: Add tasks with titles and times to specific dates.
- Schedule Overview: Display all tasks and events scheduled for a selected day.
- Reminders: Set reminders for upcoming tasks.
- Completion Tracking: Mark tasks as complete and visually track progress.

## Style Guidelines:

- Primary color: Fresh Green (#A7D1AB) to promote calm focus and a sense of growth.
- Background color: Light green (#E8F5E9), almost white, for a clean and airy feel.
- Accent color: Yellow-Green (#B3E679) to add highlights.
- Body and headline font: 'PT Sans' for readability and a modern, warm feel.
- Use minimalist icons to represent task categories and actions.
- A clean and intuitive layout to emphasize a clear distinction between different views.
- Subtle transitions to indicate task completion and schedule updates.
