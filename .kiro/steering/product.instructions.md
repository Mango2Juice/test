# Product Overview

**Doses** is a web-based Progressive Web Application (PWA) designed to assist healthcare professionals in accurately calculating medication dosages for pediatric and adult patients. The primary goal is to enhance patient safety by providing a reliable, user-friendly tool based on established medical standards. The app provides a curated database of medications organized by medical systems, diagnoses, and complaints.

## Key Features

- **Dose Calculator**: Core functionality for calculating medication dosages based on patient weight, age, and selected formulations
- **Diagnosis Guide**: Quick-reference guide for common clinical diagnoses with suggested medications and treatment notes
- **Medication Database**: Comprehensive list of pediatric and adult medications organized by categories
- **Resource Library**: Collection of useful medical equations and external references
- **Offline Support**: PWA capabilities allow usagewithout internet connectivity
- **Safety-First Design**: Built-in warnings, error handling, and validation to prevent dosage errors
- **Calculation history** - Track previous calculations and detect duplicate dosing
- **User-friendly interface** - Designed specifically for healthcare professionals

## Target Users

Healthcare professionals including doctors, nurses, pharmacists, and other medical practitioners working in various care settings who need quick, accurate medication dosage calculations.

## Safety Notice

This is an informational tool only and not a substitute for professional medical judgment. All calculations must be verified by qualified healthcare professionals before administration.

## Technical Approach

- **Offline-first design** - Core functionality works without internet connection
- **Type-safe calculations** - TypeScript ensures calculation accuracy
- **Comprehensive testing** - Vitest testing with coverage for critical calculation logic
- **Accessibility compliant** - Following WCAG guidelines for healthcare applications
- **Performance optimized** - Fast calculations and smooth user experience
